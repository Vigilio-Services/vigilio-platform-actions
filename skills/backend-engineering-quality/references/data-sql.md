## Uso Desde La Skill

1. Identificar owner de datos, dialecto, tooling e invariantes.
2. Resolver la skill del stack y revisar schema, queries, migrations y tests reales.
3. Aplicar forward, verificacion y rollback/recovery definidos por la guia.
4. Conservar evidencia de integridad, planes aplicables y riesgos residuales.
