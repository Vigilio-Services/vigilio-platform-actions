# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `v1.x` | Yes |

## Reporting a vulnerability

Reportar vulnerabilidades mediante GitHub Security Advisories o canal interno de seguridad.

No abrir issues publicos con secretos, credenciales, tokens, PoC explotable o detalles sensibles.

## Scope

- Reusable workflows.
- Composite actions.
- Paquete `@vigilioyonatan/devsecops-governance`.
- Politicas de branch/stage, PR, commit y Jira.

## Response

- Critico: triage el mismo dia laboral.
- Alto: triage en 2 dias laborales.
- Medio/bajo: backlog priorizado.
